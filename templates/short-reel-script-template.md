# Short Reel Script Template (30–90 sec)

> Copy karo → `scripts/YYYY-MM-DD-topic-short.md` naam se save karo → bharo.

## Meta
- **Topic:**
- **Ek line ka sawaal jo reel answer karegi:**
- **Type:** Explainer / Argument-Rebuttal / Takeaway / Shocking-fact
- **Target length:** 30s / 60s / 90s
- **Emotion jo chahiye:** curiosity / anger / awe / "ab samjha"
- **Long video se juda hai?** (link / no)
