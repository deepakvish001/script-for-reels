## 2. Structure jo 16 mein baar-baar dikhta hai

```
0:00  COLD OPEN    : dated story / celebrity news / personal moment / viral clip / research stat
0:30  STAKES       : "yeh simple nahi hai" + promise ("shock ho jaoge", "last tak sunna")
1:00  FOUNDATION   : "pehle ek cheez samajhna zaroori hai": concept zero se, ghar ki misaal se
3:00  SPONSOR      : topic se bridge ("jab bhi nayi technology aati hai...") → read → "khair, wapas topic pe"
5:00  STORY CHAIN  : 2–4 kahaniyan (dates, naam, jagah); har ek ke end mein "ab yeh kyun bata raha hoon?"
12:00 DOTS CONNECT : "pattern wahi hai", "itne coincidences nahi ho sakte"
16:00 PAYOFF       : naam reveal / callback ("woh scientist the Oppenheimer") / "ab samajh aaya?"
18:00 CLOSE        : life lesson ya provocative sawaal → "comments mein discuss" → abrupt "that's it"
```

## 4. Sponsor integration ka formula (10/16 videos)

1. **Timing:** 2:30–6:00 ke beech, jab hook aur stakes set ho chuke hon.
2. **Bridge:** topic se ek universal line, phir sponsor ka category.
   - "Jab bhi nayi technology aati hai, job market do hisson mein bant jaata hai..." → AI course
   - "Business mein product se zyada system matter karta hai..." → ERP software
   - "Is waqt bhi superpower US hai..." → US stocks app
   - "Waqt kabhi ek jaisa nahi rehta..." → insurance
3. **Read:** problem → product → 3 features → offer / coupon → "link description aur pinned comment mein".
4. **Exit:** "Khair, wapas aate hain apne topic pe."
5. **Pattern:** sponsors **career / AI upskilling** heavy hain. Unki audience 18–30 ke students aur
   working professionals hain.
