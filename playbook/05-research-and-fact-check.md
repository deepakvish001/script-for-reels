# Research and Fact-Check Workflow

Rishabh ka apna research method (podcast mein unke apne shabdon ka saar):

1. **Research khud karo.** Team editing aur backend sambhaale, research nahi, kyunki
   "public aapka chehra dekh ke trust karti hai."
2. **Dono ecosystems ke newspapers padho.** Left-leaning bhi, right-leaning bhi. Conclusion
   beech se nikalta hai.
3. **Books.**
4. **Government records.**
5. **Ground reality.** Jo log wahan rehte hain unse baat karo. Records hamesha poori kahani
   nahi batate.
6. **Loophole mat chhodo.** "Mahine mein 6–7 video" se better hai "1 video bina loophole."

Unki criticism yahi hai ki facts par sawaal uthte hain. Isliye niche waala process unke
method ko **verify-first** banata hai.

---

## 1. Research pipeline (har video ke liye)

```
Topic → Core question → Source sweep (both sides) → Fact sheet → Story outline → Script → Fact-check pass → Record
```

### Step 1: Core question
Ek sawaal likho jiska jawaab video dega. "BlackRock ke baare mein" nahi, balki
"**Kya BlackRock sach mein companies ke faisle control karta hai, ya sirf investors ka paisa
manage karta hai?**"

### Step 2: Source sweep (minimum 8–10 sources)

| Tier | Kya | Example |
|---|---|---|
| **Tier 1 (primary)** | Original documents | Govt data (RBI, NPCI, MoSPI, Census, PIB), court judgments, company annual reports, SEC filings, Parliament Q&A |
| **Tier 2 (quality reporting)** | Reputed reporting jo primary ko cite kare | Reuters, The Hindu, Indian Express, Mint, ET, BBC, Bloomberg |
| **Tier 3 (perspectives)** | Opinion, books, think tanks, dono taraf ke | Left- aur right-leaning dono columns, academic papers |
| **Tier 4 (ground)** | Interviews, local reporters, khud ka experience | Clearly label: "mera experience" / "ek local ne bataya" |

**Rule:** Tier 3–4 se **opinion** lo, **facts** sirf Tier 1–2 se.

### Step 3: Fact sheet (script likhne se pehle)

| # | Claim | Number / date | Source (link) | Tier | Doosra source match karta hai? |
|---|---|---|---|---|---|
| 1 | | | | | ✅ / ❌ |

**Do independent sources** wala claim hi script mein jaaye. Ek source wala claim "reportedly"
ke saath bolo.

### Step 4: Script mein inline tags
Har factual line ke aage `[SRC: name, year]` likho. Editor isse screen par source tag
lagayega aur tum description mein list doge.

### Step 5: Fact-check pass (record karne se pehle)
- [ ] Har number ka unit sahi hai (crore vs billion, % vs percentage points)
- [ ] Har date / saal check kiya
- [ ] Quote exact hai, aur context ke saath hai
- [ ] Koi bhi line puri community ya religion par blanket statement toh nahi?
- [ ] "Sabse bada / pehla / only" jaise superlatives verify kiye
- [ ] Doosre paksh ka strongest argument script mein hai
- [ ] Jo cheez opinion hai, woh opinion ki tarah boli gayi hai ("mera maanna hai...")

---

## 2. Opinion vs fact: bolne ka tarika

| Type | Kaise bolo |
|---|---|
| Verified fact | "RBI ke 2025 data ke mutabik..." (screen par source) |
| Reported claim | "Reuters ki report kehti hai ki..." |
| Interpretation | "Mera maanna hai ki iska matlab ___ hai." |
| Lived experience | "Main ___ mein raha hoon. Mera experience yeh tha." (ise data ki tarah pesh mat karo) |
| Speculation | "Yeh sirf ek theory hai, par sochne layak hai..." |

---

## 3. Sensitive topics (religion, caste, communities, politicians)

- **Specific raho.** Incident, data, policy ya statement par baat karo, poori community par nahi.
- **Naam lena ho toh unka asli clip ya quote dikhao.** Paraphrase par ilzaam mat lagao.
- **Defamation se bacho.** Kisi ko "chor" ya "agent" bolna hai toh court ya official record
  chahiye. Warna "sawaal" ki tarah rakho.
- **Platform rules:** hate speech, violence ke liye uksaana, aur misinformation (khaaskar
  health aur elections) par strike aati hai. Ek strike = reach down.

## 4. Useful primary source list (India focus)

- RBI: https://www.rbi.org.in (reports, data, bulletins)
- NPCI (UPI stats): https://www.npci.org.in
- PIB (govt press releases): https://pib.gov.in
- MoSPI / NSO data: https://mospi.gov.in
- Census / NFHS: https://censusindia.gov.in , https://rchiips.org/nfhs
- Lok Sabha / Rajya Sabha Q&A: https://sansad.in
- Supreme Court judgments: https://main.sci.gov.in , https://indiankanoon.org
- Company filings: BSE/NSE announcements, annual reports; US: https://www.sec.gov/edgar
- Fact-checkers (cross-check viral claims): BOOM, Alt News, Factly, PIB Fact Check
