# script-for-reels

**Thoughtful, impactful, detailed analysis** wali Hinglish videos ke liye script playbook,
**short-form (Reels/Shorts)** aur **long-form (YouTube)** dono ke liye.

Base: creator **Rishabh Bidhuri** (Instagram/YouTube `@rishabh.gujjar.38`) ki videos ka
scene-by-scene analysis. Goal unhe copy karna nahi hai. Goal unki **techniques samajhna** hai,
aur unme **fact-checking + fairness** jodkar unse behtar content banana hai.

## Formula, ek line mein

> **Mystery label → aapki life se connection → "sab adhoori kahani batate hain" →
> "maine khod ke asli wajah nikaali" → bold thesis → chalo shuru se samajhte hain.**
>
> Aur aapka edge: **har claim ka source screen par + doosri side ka strongest argument.**

## Naya script likhwana ho toh

Is repo mein Claude ke saath kaam karte waqt bas likho:

> "UPI par 60 sec ki reel likho" / "BCCI par 15 min ki long video script likho"

[`CLAUDE.md`](CLAUDE.md) mein instructions hain, taaki har nayi session isi playbook ko follow kare.
Apni scripts `scripts/` folder mein save karo.
